# Prachi Sawant Portfolio

A responsive React + CSS portfolio built with Vite.

## Run locally
1. Install Node.js (LTS).
2. Open this folder in VS Code.
3. Run `npm install`
4. Run `npm run dev`
5. Open the local URL shown in the terminal.

## Before publishing
- Your email address from the resume is already added to the contact section.
- Your uploaded resume is included at `public/Prachi-Ravindra-Sawant-Resume.pdf` with a download link.
- Review internship dates and project descriptions for accuracy.
- Add GitHub links or project demos if available.

## Profile photo
Your uploaded profile photo is already included at `public/profile.jpg` and displayed in the hero section.

## Deploy
You can deploy the project on Vercel or Netlify. Build command: `npm run build`; output directory: `dist`.
